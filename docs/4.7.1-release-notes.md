# CluedIn Connector Release Notes - 4.7.1

## New Features
- Initial implementation and scaffolding for Amazon S3 connector, including:
  - S3 connector project and structure (`Connector.S3`)
  - S3 job data and factory
  - S3 connector provider and registration
  - Interface abstraction for external storage clients
- Refactored DataLake connectors to use a generic external storage interface, enabling support for S3 and other storage backends.

## Improvements
- Improved codebase modularity and extensibility for new storage providers.
- Updated dependency injection and registration patterns for connectors.

## Fixes
- Fixed build and interface implementation issues for new and existing connectors after refactor.

## Notes
- S3 connector logic is scaffolded but not yet fully implemented. Further development is required for production use.
- All existing connectors continue to function as before, with no breaking changes to Azure Data Lake or OneLake connectors.
